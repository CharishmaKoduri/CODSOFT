# How to Run the Projects

Open terminal or command prompt in the project folder and run the following commands.



## Run Tic-Tac-Toe AI

```bash
python tic_tac_toe_ai.py
```


## Run AI Chatbot

```bash
python chatbot.py
```



## Run Product Recommendation System

```bash
python recommendation_system.py
```


## Requirements

Install required libraries before running the projects.

```bash
pip install pandas scikit-learn
```

Recommended Python Version:

```text
Python 3.8 or above
```
